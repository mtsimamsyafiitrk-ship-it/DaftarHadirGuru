# Daftar Hadir Guru

## Overview
This application provides a comprehensive system for managing attendance for teachers. It allows administrators to track when teachers are present and absent, and it generates reports based on attendance data.

## Features
- **Real-time Attendance Tracking**: View and manage attendance in real time.
- **User Management**: Manage teacher and admin accounts with role-based access control.
- **Reporting**: Generate reports for attendance over specified periods.
- **Notifications**: Alert teachers via email or SMS about their attendance status.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mtsimamsyafiitrk/DaftarHadirGuru.git
   ```
2. Navigate into the project directory:
   ```bash
   cd DaftarHadirGuru
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

## Usage
- To record attendance, log in as an admin or teacher and navigate to the attendance section.
- You can view attendance records and generate reports from the dashboard.
